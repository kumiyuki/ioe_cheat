# Oplius
Exploit IOE

Find `ioe-string` in resources.js for string.

# How to use?
Press `/` on keyboard while game loaded. After that an input will appear.\
Type `help` in and make sure you have console (Ctrl + Shift + I) or (F12) turned before.

# How to get modules
use:

```js
window.__require(module_name)
```
to get the module.

Most modules is included in `resources/index.js`. You can view it in debugger.
